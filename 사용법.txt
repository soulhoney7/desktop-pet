■ 데스크탑 펫 — exe 만들기 & 사용법

[1] exe 만들기 (한 번만)
 1. 압축을 푼 폴더에서 "빌드.bat"을 더블클릭하세요.
 2. 필요한 프로그램을 내려받고(처음 5~10분) exe를 만들어요(2~5분). 기다리기만 하면 돼요.
 3. "완성!"이 나오면 같은 폴더에 "데스크탑펫.exe"가 생겨요.
 ※ 파이썬이 없다고 나오면 python.org에서 3.12 버전을 설치하세요.
    설치 첫 화면에서 "Add python.exe to PATH"를 꼭 체크하세요.

[2] 쓰기
 - "데스크탑펫.exe"를 더블클릭하면 바로 켜져요.
 - 예전 버전이 켜져 있는 상태에서 새 exe를 켜면 "끄고 새로 켤까요?"가 나와요 → "예"
 - 다른 컴퓨터에서는 데스크탑펫.exe 파일 하나만 있으면 돼요. (파이썬 설치 필요 없음)
 - exe를 처음 켤 때 "Windows의 PC 보호" 파란 창이 뜨면: "추가 정보" → "실행"
   (직접 만든 프로그램이라 서명이 없어서 그래요)
 - exe는 켤 때마다 몇 초 정도 걸려요.
 - 자동 업데이트: 새 버전이 나오면 알아서 받아 두고 알려 줘요 → 알림이나 "지금 업데이트하기"를 누르면
   잠깐 꺼졌다가 새 버전으로 다시 켜져요 (펫·설정은 그대로). 더 이상 exe를 새로 받을 필요가 없어요.

[3] 펫 추가 — 설정창에서 해요
 설정창 여는 법: 처음 켜면 자동으로 열림 / 작업표시줄 오른쪽 발바닥 아이콘 / 펫 우클릭 → 설정 열기
 넣는 방법 (여러 장 한꺼번에 가능)
  - 사진 파일 여러 개를 설정창에 끌어다 놓기
  - 사진이 든 폴더를 통째로 끌어다 놓기 → 안의 사진 전부 추가
  - "+ 사진 추가" 버튼 → Ctrl이나 Shift로 여러 장 선택
  - 웹 그림을 그대로 끌어다 놓기, 또는 그림을 복사해서 설정창에서 Ctrl+V
 지원 형식: PNG, JPG/JPEG/JFIF, WEBP, GIF, BMP, TIFF, HEIC/HEIF(아이폰 사진), AVIF, ICO
  - 움직이는 GIF는 첫 장면을 써요.
 처리 과정
  - 배경이 이미 투명한 PNG/WEBP/GIF → 그대로 사용
  - 그 외 → AI가 주인공을 찾아 배경을 지우고, 주변 작은 조각도 정리
  - 빈 여백을 잘라내고 펫으로 저장 → 바로 화면에 나와서 돌아다님
  - 한 장에 2~3초 정도. 맨 처음 한 번은 배경 제거 모델(약 170MB)을 내려받아요.

[4] 펫이 하는 일
 걷기, 뛰기, 깡충깡충, 점프, 공중제비, 춤추기(♪), 앉아 쉬기, 낮잠(z),
 두리번거리기(?), 마우스 쫓아가기(!), 벽 타고 올라갔다가 뛰어내리기,
 펫끼리 만나면 하트 주고받기(♥), 세게 던지면 어지러워하기(★)
 펫끼리는 겹치지 않고, 부딪히면 "콩!" 튕김 / 던진 펫이 맞으면 "뿅!" / 자는 펫을 맞히면 💢

[4-0] 간식 · 기차놀이 · 쉬는 시간 · 퇴근임박
 - 우클릭 → "간식 주기 🍪": 펫들이 달려가서 먼저 닿은 펫이 냠냠
 - 가끔 한 줄로 칙칙폭폭 기차놀이. 마주친 펫은 꼬리 칸에 탑승, 벽에선 대장이 친구들 넘어서 방향 전환
   우클릭 → "기차놀이 🚂 (얘가 대장)" / "평소 기차 대장으로 정하기 👑"
 - 50분마다 기지개 켜며 쉬자고 알려 줌
 - 퇴근임박 모드(평일): 퇴근 1시간 전부터 졸고 "퇴근까지 ○분!", 퇴근 시간엔 다 같이 축하
   퇴근 시간은 설정창에서 30분 단위로 선택 (기본 18:00)
 - 여러 마리가 함께 찍힌 사진은 한 펫으로 붙어 다니며 캐릭터마다 각자 통통 튐

[4-1] 열린 창 위에서 놀기
 - 새 창을 열면 근처 펫이 웅크렸다가 창 위로 뛰어올라가요. (최소화했다 다시 연 창도)
 - 평소에도 가끔 스스로 창 위로 점프하고, 창 위를 걸어 다니다 끝에서 돌아서거나 뛰어내려요.
 - 창을 끌어서 옮기면 펫이 같이 타고 다녀요.
 - 창을 닫거나, 최소화하거나, 다른 창으로 가리면 깜짝 놀라며 떨어져요.
 - 끄고 싶으면 설정창의 "열린 창 위에서 놀기" 체크를 해제하세요.

[5] 펫과 놀기
 - 집어서 던지기 (집으면 대롱대롱 흔들려요)
 - 더블클릭: 점프 / 자고 있으면 깜짝 깨요
 - 펫 위에서 마우스를 문지르기: 쓰다듬기 → 하트
 - 우클릭: 점프, 공중제비, 춤추기, 재우기, 벽 타기, 숨기기, 설정 열기

[6] 설정창  (설정창의 "? 사용법" 버튼으로 프로그램 안에서도 설명서를 볼 수 있어요)
 - 작업표시줄 오른쪽(^ 숨겨진 아이콘) 분홍 발바닥 아이콘 클릭
 - 펫 켜기·끄기, 펫별 크기, 전체 크기, 삭제(카드 오른쪽 위 ×), 프로그램 종료
 - 방향키(아무거나) 1초 안에 3번 → 펫이 싹 사라짐, 다시 3번 → 돌아옴
 - 발바닥 아이콘 우클릭 → "30분 동안 숨기기"
 - PPT 발표·영상 전체화면·게임 중에는 자동으로 숨음 ("전체화면일 때 숨기기"로 끄고 켜기)
 - 펫 이미지와 설정은 %APPDATA%\DesktopPet 폴더에 저장돼요.

[7] 컴퓨터 켤 때 자동 실행
 Win+R → shell:startup 입력 → 열린 폴더에 데스크탑펫.exe의 바로가기를 넣으세요.
